Automated Picking System

Background

In a prototype warehouse kitting setup, I programmed the TM5-700 collaborative robot to perform automated pick-and-place operations for different products identified by the Intel Realsense Camera. The manipulator is required to detect target items based on colour, pick them using a suction gripper, and place them into an outbound box for kitting.

Project Objectives

  • Enable the TM5-700 manipulator to perform automated pick-and-place operations for warehouse kitting.
  • Integrate the Intel Realsense Camera to detect target products for picking.
  • Control the suction gripper through digital output signals.

System Implementation

The TM5-700 manipulator is controlled through the TM ROS driver, which provides service-based communication with the TMFlow controller. The Intel Realsense camera is interfaced with the manipulator through USB communication to provide depth measurements for the vertical approach during pick-and-place operations and RGB readings for colour classification. The Robotiq suction gripper is "plug and play" compatible with the TM5-700 manipulator and is activated through digital outputs.

3 main ROS service clients are used: SetPositions for motion control, SetIO for digital output control of the suction gripper, and SendScript for executing TMFlow script commands. Service-client communication is used instead of publisher-subscriber as the request-response mechanism ensures each command has finished executing before the next action is performed and prevents conflicting robot actions.

A custom ROS node command_publisher is created to subscribe to the camera topics and to control the overall system execution. The RGB topic returns a String datatype from the colour-based detection results. The average_depth topic returns a Float datatype that provides depth measurements from the center of the camera to the target. The node publishes to the command topic that informs the robot execution node move on the actions to be performed for the TM5-700. The node subscribes to the feedback topic that returns a String datatype indicating if the TM5-700 manipulator is currently executing an action or has completed it.

The robot execution is controlled by a custom ROS node move. Based on the value subscribed from the command topic, the node prepares the service request. The node first subscribes to the tool_pose topic to obtain the tool position and orientation. The quaternion orientation is converted into Euler angles to allow Cartesian point-to-point motion commands. The Cartesian coordinates are modified and sent through the SetPositions service, which moves the TM5-700 tool to the modified coordinates. After the service call is completed, the move node publishes to the feedback topic that the TM5-700 manipulator has finished the action.

During the pick stage, the TM5-700 determines if the object is the intended product for the kitting process using the RGB readings. If it is, the required Z-axis displacement is calculated using the depth measurement. A fixed negatives Y-axis offset is applied to compensate for the physical displacement between the camera and the suction tool. Once the manipulator is in place with the tool physically on the product, the suction gripper is activated using the SetIO service to attach the product.

After picking, the manipulator lifts the product by reversing the Z-axis motion and then translating across the X-axis towards the outbound lane. For placement, the TM5-700 lowers the product using the same depth-based approach. The suction gripper is then deactivated to release the product. Finally, the SendScript service is used to send a ScriptExit() command. This is required to ensure that the TM5-700 exits listen mode on the TMFlow to end the current script execution cycle and to be ready for the next pick-and-place operation.

Challenges and Solutions

Compensation between Camera and Tool

One of the main challenges encountered during the development of the kitting system was ensuring reliable alignment between the camera detection and the physical position of the suction gripper. The depth readings are obtained from the Intel RealSense camera, which is mounted at an offset relative to the end effector. As a result, the detected object position does not directly correspond to the tool center point of the manipulator. This was addressed by introducing a fixed negative Y-axis offset during the pick and place stages to compensate for the physical displacement between the camera and the suction tool. This ensured that the tool is centered on the product before activating the suction gripper.

Conclusion

The kitting system successfully achieved automated pick-and-place operations within the defined workspace, allowing the TM5-700 manipulator to identify, pick, and place different products using RGB-based detection and depth guided positioning. By integrating vision sensing, service-based robot control, and coordinated command execution, the system was able to perform consistent and reliable kitting operations.

To achieve this, I implemented the TM ROS driver to control the TM5-700 externally. The command node (command_publisher) and a robot execution node (move) interfaces directly with the TM ROS driver through service clients. This enabled command driven manipulation using SetPositions, SetIO, and SendScript, enabling execution of manipulator motion and suction. In addition, I implemented camera to tool offset compensation to ensure picking accuracy, as well as a feedback-based sequencing mechanism through the publisher-subscriber method to prevent conflicting robot commands.

This project demonstrates my ability to design and implement industrial robotic automation systems using ROS 2, as well as integrate vision sensors, suction-based end-effectors, and robotic manipulators into an automation system that meets project requirements.
